4. MOST IMPORTANT AUTHENTICATION SECURITY WEAKNESS

Unauthenticated password reset without proof of account ownership.

Location:
src/app/api/auth/forgot-password/route.ts:17-37, with surrounding 7,19-25,39-44.

Confirmed behavior:
- POST route requires no session.
- Caller supplies an email/username.
- findUserByLogin resolves the account.
- If newPassword is supplied, lines 31-32 hash it and update users.passwordHash.
- A mockToken is generated with Math.random().
- No source file in src/ stores, validates, expires, or otherwise verifies that token.
- No delivery channel or token table exists in the dependency/source footprint examined.
- There is no demonstrated rate limiter in the repository.

Why it matters:
An anonymous caller who knows an account identifier could set that account's password through this route and then log in.

The report identifies a hardcoded admin seed account at src/db/seed.ts:205-215 as further impact context.
